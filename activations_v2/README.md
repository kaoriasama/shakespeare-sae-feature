# Activation matrices

Download the matrices from the Zenodo record linked in the repository README and place the following files in this directory:

- `{g2_L4,g2_L11,g2_L22,g3_L9,g3_L17,g3_L29}_firing.npz`
- `{g2_L4,g2_L11,g2_L22,g3_L9,g3_L17,g3_L29}_mean_act.npz`

The braces denote the six model-layer prefixes; each prefix has one firing matrix and one mean-activation matrix.
