The source texts are attributed to *The Folger Shakespeare*, edited by B. A. Mowat and P. Werstine, Folger Shakespeare Library, <https://shakespeare.folger.edu/>. The Folger source is licensed under the [Creative Commons Attribution-NonCommercial 3.0 Unported License](https://creativecommons.org/licenses/by-nc/3.0/).

The redistributed data are modified materials: the source TEI was transformed into analysis chunks, and statistical summaries were computed from those chunks and the resulting SAE activations. Consult `corpus_raw/provenance.md` for source-file verification records.

Two files added for the camera-ready version call for specific notes. `reports/pattern_feature_excerpts.txt` quotes passages from the Folger Shakespeare verbatim (up to about 1,400 characters per chunk) and is covered by the Folger terms above (attribution, non-commercial use, and indication of changes). The columns prefixed `np_` in `reports/pattern_feature_ids.csv`, and the file `pattern_feature_neuronpedia.json` in the Zenodo record (https://doi.org/10.5281/zenodo.22112879), contain data retrieved from the Neuronpedia public API (https://www.neuronpedia.org) and are redistributed only to allow the paper's results to be reproduced.
